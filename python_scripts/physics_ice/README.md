# Ice Physics Utility Scripts

This directory contains scripts used to generate, transform, and inspect the water-ice cross-section tables distributed with the release.

Representative uses include:

- regenerating vibrational-excitation cumulative tables
- building or inspecting finite-q dielectric-model products
- generating blended elastic datasets
- plotting and comparing ice cross sections

These scripts are primarily development and reproducibility utilities. The executable itself uses the `.dat` files installed under `${G4LEDATA}/dna/`.
